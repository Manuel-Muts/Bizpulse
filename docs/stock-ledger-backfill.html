Stock History Backfill — Dry Run

Preview a November 1, 2025 opening balance for non-Petrol inventory using recorded sales, stock additions, and manual adjustments. The preview is read-only; applying ready items is a separate, confirmed action.

The item's system creation date does not exclude backdated activity. Historical balances are inferred from current quantity and dated transactions on or after November 1, 2025. Existing sales and stock addition records are not modified. Petrol remains on its separate dip tracking.

This page only reports what has been entered so far; it cannot verify that data entry is complete through today. If an item has no dated activity, its current quantity is used as an assumed November 1 opening balance. Items with additions only have those additions subtracted to infer opening stock.

Historical values are only as complete as the source records. Manual stock changes that were never recorded, missing transactions, and deleted records cannot be reconstructed automatically.

Use the same browser session as the business app. For local use, run node docs\dev-server.js from the repository root, sign in at http://localhost:3000, then open http://localhost:3000/stock-ledger-backfill.html.
